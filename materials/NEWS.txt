=========================================================
This file documents exploreGLM changes since version 0.1
=========================================================

CHANGES (user-visible):

- Change the use of 'exploreglm' function: 
	Now 'formula' is required instead of the argument 'y'.

- Change the use of 'prepareData' function:
	Now only 'id' is required for the identifier variable.
	'idname' and 'idpos' are removed of the prepareData arguments.
